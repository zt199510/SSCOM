# Sscom

做一个干净的本地串口调试助手：打开串口，用 HEX 和 ASCII 两种视图显示同一批接收字节，显示一致、不丢数、不错位。

范围仅限 Day 1–2：串口枚举与刷新、串口参数配置、打开与关闭、手动 ASCII / HEX 发送、共享字节缓冲的双接收视图、收发字节统计，以及打开失败、断线和重新打开的处理。

Day 3–4 增加：定时发送、快捷发送分组（JSON 持久化与导入导出）、发送历史。三种发送都走同一条发送路径。

发送历史的例外：历史只记录写入成功的发送，并且最多保留 2000 条，超出后丢弃最旧的记录。这是对“记录每一次发送”的明确例外，防止短间隔定时发送导致内存无限增长。无效内容或写入失败不进历史，但一定会在状态栏显示原因；定时发送因此停止时，定时状态旁也会注明原因。完整的发送审计日志属于以后的“日志落盘”功能，不在本次范围内。
